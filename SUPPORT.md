# Support

Satin is maintained as an open source project without a guaranteed response
time or private end-user support channel.

- Use the bug report form for reproducible defects.
- Use the feature request form for focused product proposals.
- Include the Satin version, macOS version, reproduction steps, and sanitized
  logs when relevant.
- Check the README, `docs/`, and existing issues before opening a new issue.

Never post credentials, private terminal output, signing material, or an
unreleased vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md)
for security reports.
